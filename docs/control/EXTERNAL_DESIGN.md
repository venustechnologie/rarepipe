# Biological Capability Universe, Phase 1 — design

The previous phase proved a capability gap can drive a search. It searched a corpus of fifteen
claims, so "nothing found" said almost nothing. This phase connects a **real external evidence
source** and asks whether the epistemology survives contact with it:

```
desired function → capability gap → external evidence search → physical capability → recompile
```

**Build authorization: Phase 1 only.** No universal biomedical knowledge graph, no indiscriminate
ingestion, no catalogue of all drugs or genes or molecules, no docking, no molecular simulation, no
clinical prediction, no therapeutic ranking, no probabilities of success, no new solvers.

Outputs: [`MVA_CAPABILITY_GAPS_EXTERNAL.md`](MVA_CAPABILITY_GAPS_EXTERNAL.md) and
[`MVA_CAPABILITY_DISCOVERY_TRACE.md`](MVA_CAPABILITY_DISCOVERY_TRACE.md), generated by
`tools/control/compile_mva_external_gaps.py`. The baseline they are measured against,
[`MVA_CAPABILITY_GAPS.md`](MVA_CAPABILITY_GAPS.md), stays separately runnable.

## Retrieval is not grounding

Finding a source does not create a capability. Seven states are kept apart and none implies the next:

```
SOURCE_FOUND → SOURCE_VERIFIED → CLAIM_EXTRACTED → CLAIM_GROUNDED
             → CAPABILITY_CANDIDATE → CAPABILITY_ENTITLED → GROUNDED_CAPABILITY
```

## Retrieval and compilation are separate steps

`tools/control/retrieve_capability_evidence.py` is the only networked part. It writes a versioned
corpus snapshot; the compiler reads only that. Hitting a live index at compile time would make every
report unreproducible and make CI depend on somebody else's uptime. A test asserts no module inside
the compiler reaches the network.

Queries pass the repository's existing guards before they leave: the Stage 04 case-identity guard,
which no phase lifts, and the therapy filter, so a functional search cannot drift into an
intervention hunt. A test asserts every query in the committed snapshot is free of case-specific
content. The snapshot stores abstracts and metadata only — **not** full text, even where the licence
would permit it — which bounds the phase honestly: a claim whose support lives in a figure or a
methods section cannot be grounded here.

## The search is functional, not nominal

"What papers discuss BUB1B" finds the literature about the broken gene, which is exactly the
literature that cannot contain a bypass. Queries are derived from the interface — the output, the
direction, the forbidden dependency, the context — plus a class of mechanism that might satisfy it.
The model may propose mechanism classes; its output is only ever a query string. A test asserts no
query names the gene.

37 queries produced **91 real documents** from Europe PMC.

## What the validators added

| Check | What it refuses |
|---|---|
| span grounding | a span that is not in the stored document, character for character |
| causal grade | an association standing in for a causal capability |
| functional semantics | a reported increase standing in for a restored function |
| forbidden-named-in-span | independence certified from text that names the forbidden component |
| independence unestablished | a bypass claim no source asserts is independent |
| compartment transfer | whole blood standing in for the intracellular pool |

Two of these were forced by real sources rather than imagined:

**Independence is never a default.** A newly discovered entity has no ancestry in the repository's
inventory, so a forbidden-dependency check over that inventory alone passes vacuously for anything
unfamiliar — which would make "we found a bypass" the automatic answer for every new protein. Claims
therefore declare the dependencies their own sources state, those become edges in the ancestry graph,
and a bypass candidate whose independence no source asserts is `INDEPENDENCE_UNESTABLISHED`. Absence
of a recorded link is not evidence of absence.

**Ancestry is scoped to the candidate's own mechanism.** My first version walked upward from the
output, which finds the forbidden component for *every* candidate — the inventory records that it
drives these outputs; that is why the gaps exist. The walk now starts from what the mechanism rests
on. This was a real bug, and it made every candidate look dependent.

**A state is not a level.** `checkpoint_activation = normal` means division is held when attachment
is wrong *and released when it is right*. A cell simply prevented from dividing would read as maximal
activation on a level-only representation, and is the loss of the function rather than the function.
So each state carries a specification of what it requires and what it excludes, and
`increase(X) ⇒ X = normal` holds only through a `FunctionalEffectMapping` with evidence of its own.
No such mapping is registered, because none is justified by anything retrieved.

## What the run found

Four gaps, 91 documents, five claims extracted with verbatim spans, **zero capabilities grounded**,
and four interfaces whose epistemic state moved against the recorded baseline.

| Gap | Before | After | What changed |
|---|---|---|---|
| A — checkpoint activation | `ONLY_DEPENDENT_CAPABILITIES_FOUND` | same | an external candidate was examined and refused for a named reason |
| B — checkpoint silencing | `ONLY_DEPENDENT_CAPABILITIES_FOUND` | `NO_GROUNDED_CAPABILITY` | the candidates no longer share one reason |
| C — chromosome alignment | `ONLY_DEPENDENT_CAPABILITIES_FOUND` | `NO_GROUNDED_CAPABILITY` | same |
| D — intracellular cofactor | `CONTEXT_ONLY_CAPABILITY` | same | the compartment objection is answered; a tissue objection replaces it |

Gaps B and C moved because three candidates now fail for **three different reasons**, which is finer
than one shared blocker: one routes through the forbidden node, one names it in the very text that
supports it, and one simply has no source asserting it works without it. Those are three different
states of knowledge.

Gap D is the substantive advance. The repository's own claim measured the circulating pool, which is
why the step was blocked. A retrieved human trial measured the **tissue** pool after the agent the
route proposes. The compartment objection is answered and a different one — the tissue and disease
state the measurement was made in — is what remains, carried as a transfer gap.

## Auditing the repository's own citations

The grounding rule applied backwards. All six citations the case rests on were retrieved, and the
attribution the chain makes to each was checked against the document. Four hold. One does not:
the chain cites a paper for a null nicotinic-acid result on the altered protein, and the retrieved
document is about white adipocytes adapting to cooler temperatures — it contains neither "niacin",
"nicotinic", nor "BubR1". Everything derived from that edge rests on an attribution the document
does not support.

A seventh finding is an absence: a strong, directly relevant human trial is named in the repository
and **used nowhere in the chain**, while the mis-attributed paper is used for the niacin claims.

## Proof status

**Proof B, on a substantial external corpus.** Candidates were retrieved, validators rejected each
for a concrete reason, and the reports state exactly what was inspected and what capability is still
missing.

**Proof A, on a toy corpus only.** The full loop — external-style source → grounded claim → grounded
capability → architecture delta, with nobody editing a realization — is demonstrated and gated, and
it has never fired on real evidence. That is the honest status.

## Proof gates and mutation testing

Sixteen gates in `tests/test_external_gates.py`, mapped in
[`EXTERNAL_REQUIREMENTS.md`](EXTERNAL_REQUIREMENTS.md). All passed on the first run, so each of the
fourteen properties the PRD names was broken deliberately, plus two more: source resolution, span
grounding, entity identity, input match, output match, direction, causal type, compartment, context,
forbidden ancestry, independence-as-default, contradiction propagation, architecture recompilation,
evidence carried into the recompile, digest staleness and corpus accounting. All sixteen were caught.
