# Capability Gap Discovery & Grounding Compiler (Part 2) — design

The previous phase could say *to build this architecture we would need a piece that does X*. This
one asks whether any known piece satisfies that functional specification:

```
missing function -> search specification -> candidate -> evidence -> capability -> recompile
```

and not:

```
capability gap -> model guess -> registry
```

**Build authorization: this phase only.** No exhaustive catalogue of genes, drugs, molecules or
proteins. No chemical search engine, no docking, no structure prediction, no molecular dynamics, no
universal biomedical knowledge graph, no thousands of agents, no virtual combinatorial screening, no
invented probabilities of success, no recommendation engine. Each of those becomes a *provider*
behind one interface later. None of them is the compiler.

Output: [`MVA_CAPABILITY_GAPS.md`](MVA_CAPABILITY_GAPS.md), generated by
`tools/control/compile_mva_gaps.py` and checked for staleness by a test.

## The division of labour

> Agents discover possibilities. Evidence establishes claims. Deterministic code decides whether a
> capability exists.

`CapabilityCandidate -> GroundedCapability` is a transition the validators perform and nobody else.
Three independent things enforce it: the object requires `GROUNDED_CAPABILITY` provenance; the
proposals gate refuses that claim outright; and `build` is the only constructor and refuses unless
every validator passed.

The refusal is deliberately narrow. Claiming any *other* strong type stays recorded-and-ignored, so
an honest proposal carrying an over-confident label keeps its content and is typed down to what it
actually is. A grounded capability is different: the request is to skip the validators, and there is
nothing to salvage from it.

## A component cannot grade its own evidence

A candidate carries what it asserts — entity, input, output, direction, context — separately from
what any source says, so the two can be compared instead of conflated. A candidate cannot present a
sentence and then use the same sentence to certify itself. It cites **source ids a provider
returned**, not a citation the proposer typed.

## Providers

One interface, `CapabilitySourceProvider`, and two implementations, neither of which can invent
anything:

- **`RepositoryProvider`** searches the evidence inventory derived from the case's own causal chain.
  Fifteen claims across five citations. It returns claims about the required output as `hits`, and
  everything else it holds as `related`, so a multi-step candidate can be *audited step by step*
  rather than refused as fabricated.
- **`CuratedFileProvider`** reads claims a human curated into a file. Unconfigured by default: it
  contributes nothing and says so, because an empty corpus and an exhausted one must never read the
  same.

There is deliberately **no provider that asks a language model what it remembers.** A model's
recollection of a paper is not a source, and a layer built to refuse ungrounded claims must not
manufacture them at the point of entry.

## The validators

| Validator | What it refuses |
|---|---|
| vocabulary | an output that resolves to nothing the compiler can connect to a state variable |
| provenance / sources resolve | a citation no provider returned |
| contradiction | a claim the corpus records as a null or opposite result |
| entity match | a claim about a related protein, family or pathway standing in for the named one |
| **input match** | `A -> B` citing evidence for `C -> B` |
| output match | a marker associated with a function standing in for the function |
| direction match | a claim whose sign is not the one the candidate asserts |
| **gap direction** | a faithfully cited claim for the *opposite* effect, which answers nothing |
| chain complete | a claimed output no cited claim produces |
| **forbidden dependency** | a bypass whose mechanism runs upstream through the forbidden node |
| compartment / agent / system | three separate checks, so a report says which dimension broke |
| forbidden state | a candidate that would drive a state the gap forbids |
| source verified | a citation with no retrieval record, which caps the result at conditional |

`input match` and `gap direction` both exist because of real failures: the first was a bug found in
the previous phase, and the second was found while writing these gates — a source can be cited
perfectly faithfully for an effect in the wrong direction, and claim-consistency alone will not
notice.

The forbidden-dependency check walks the **whole ancestry graph** of the output under the candidate's
own mechanism, not the candidate's description of itself. Formally, for a bypass gap:

```
forbidden ∩ Ancestors(candidate_output) = ∅
```

## Three verification levels, never merged

```
SOURCE_VERIFIED              the paper exists and says this
CLAIM_GROUNDED_IN_SOURCE     the claim really is about this entity, input, output and direction
CAPABILITY_ENTITLED_FOR_CONTEXT   and it transfers to the context required
```

A verified source proves a paper exists. It does not prove the mechanism works here. Only the third
level licenses `GROUNDED`.

## No invented numbers

Permitted: `GROUNDED`, `CONDITIONAL`, `CONTEXT_MISMATCH`, `CONTRADICTED`, `EVIDENCE_INSUFFICIENT`,
`UNVERIFIED_SOURCE`, `NOT_REPRESENTABLE`. There is no confidence, no probability and no score
anywhere in this layer.

## Recompilation

Every grounded capability updates the registry, the realization is recompiled, and the delta is the
result — including when there is none. Making that work required a fix to the previous phase: adding
a primitive did not change which primitive a *declared* step used, so nothing could ever recompile
differently. Now, where a required transformation has **no declared mechanism**, the realization
compiler composes one from any registry capability that acts on it. A piece that lands on a function
nobody had a mechanism for turns the verdict without anyone hand-writing a chain for it. Where a
mechanism *was* declared, the declared one stands.

## What the MVA run produces

| Gap | Result |
|---|---|
| A — checkpoint activation without the altered protein | `ONLY_DEPENDENT_CAPABILITIES_FOUND` |
| B — checkpoint silencing without it | `ONLY_DEPENDENT_CAPABILITIES_FOUND` |
| C — chromosome alignment without it | `ONLY_DEPENDENT_CAPABILITIES_FOUND` |
| D — anything that raises the intracellular cofactor pool | `CONTEXT_ONLY_CAPABILITY` |

The three bypass gaps are the sharpest available negative: candidates *were* found, and every one
routes upstream through exactly the node the gap forbids. The inspected universe contains no
independent route to any checkpoint function. That is a stronger statement than "nothing found",
and it is only available because the ancestry check looks past the candidate's own description.

Gap D is the methodological control, since the steps after it are already grounded. Its one candidate
is the blood-to-cell transfer, rejected on compartment: the circulating pool is not the intracellular
pool. The interface moves from `UNKNOWN` to a named `CONTEXT_MISMATCH`.

Both realization targets recompile unchanged, stated with the reason rather than omitted.

## The metric

Not papers found, not candidates generated, not capabilities stored:

> the number of previously-open functional interfaces whose epistemic state changed.

Four moved in this run. The stop condition is satisfied by **Proof B**: the gaps remain open,
reproducibly, and the problem is reduced to concrete physical relations no candidate found can
satisfy.

## Proof gates and mutation testing

Fifteen gates in `tests/test_discovery_gates.py`, mapped in
[`DISCOVERY_REQUIREMENTS.md`](DISCOVERY_REQUIREMENTS.md). All thirty-eight tests passed on the first
run, so each of the twelve properties the PRD names was broken deliberately: input matching, output
matching, direction, context, forbidden ancestry, provenance, contradiction handling, registry
self-grading, the recompile trigger and staleness. Eleven were caught at once. The staleness mutation
was not — it turned out the digest test only detected changes visible in the headline fields, so a
precise test was added for two runs that reach the same verdict for different reasons. With that, all
twelve are caught.

Writing the toys also exposed three real defects: the gap's own required direction was never checked,
a chain candidate citing a real intermediate claim was refused as fabricated, and an unverified
citation blocked grounding entirely instead of capping it at conditional.
