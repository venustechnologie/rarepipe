# MVA_001 — contingent route map

Generated by `tools/control/compile_route_map.py` from `MVA_CONTINGENT_ROUTE_MAP.yaml`. Case data
and a renderer, not a new compiler layer: the existing machinery represents causal chains and
per-experiment decision rules, neither of which branches on admissible experimental outcome.

This is a city, not a route. It records every biological state the case can be in, every
experiment or observation that moves between them, every admissible outcome of each, and where
reasoning genuinely runs out. It does not say where to act: that is a downstream question, and
the views that answer it are in an appendix. No probabilities appear anywhere, because none is
grounded, and no leaf exists merely because reasoning stopped after an experiment.

## Two cell-level states, and they are not the same thing

Both are computed throughout, and conflating them was the error the target audit fixed.

**`FUNCTIONAL_CELLULAR_TARGET`** — the terminal state actually wanted, open to any physically valid route:

- `T_MIS` — low chromosome missegregation
- `T_VIA` — preserved viability
- `T_DIV` — preserved division
- `T_DEATH` — no increase in cell death

**`CANONICAL_CELLULAR_STATE`** — the full trajectory a normal cell takes, which is one
route to that state rather than the definition of it:

- `T_ALIGN` — correct chromosome alignment
- `T_ACT` — correct checkpoint activation
- `T_SIL` — correct checkpoint silencing
- `T_MIS` — low chromosome missegregation
- `T_VIA` — preserved viability
- `T_DIV` — preserved division
- `T_DEATH` — no increase in cell death

The difference is the whole point. A synthetic route that safely produces faithful segregation
is not failed for leaving the canonical BubR1 trajectory unreproduced; the endpoints it skips
are retained as mechanistic diagnostics, and the audit below records why each was reclassified.
Neither state is the disease: the organism scale is further out and carries its own unknowns.

## Target semantics audit

The cell-level endpoints were audited individually, because a target built from the canonical
BubR1 trajectory would reject any synthetic route that reaches the same terminal state another
way. Nothing was removed: every endpoint keeps its node, and the canonical state is still
computed beside the functional one.

| endpoint | verdict | retained as |
|---|---|---|
| `T_MIS` | `TERMINAL_FUNCTIONAL_REQUIREMENT` | target conjunct |
| `T_VIA` | `TERMINAL_FUNCTIONAL_REQUIREMENT` | target conjunct |
| `T_DIV` | `TERMINAL_FUNCTIONAL_REQUIREMENT` | target conjunct |
| `T_DEATH` | `TERMINAL_FUNCTIONAL_REQUIREMENT` | target conjunct |
| `T_ALIGN` | `CANONICAL_MECHANISTIC_INTERMEDIATE` | route-specific requirement for any route that works through attachment, and a mechanistic diagnostic everywhere else |
| `T_ACT` | `CANONICAL_MECHANISTIC_INTERMEDIATE_CONDITIONALLY_NECESSARY` | mechanistic diagnostic, and a safety question in its own right — see T_ACT_RISK |
| `T_SIL` | `CANONICAL_MECHANISTIC_INTERMEDIATE_DOUBLY_CONDITIONAL` | route-specific requirement for any route that restores checkpoint signalling |
| `T_ACT_RISK` | `ORGANISM_ADVANCEMENT_RISK_GATE` | target conjunct |

| destination | is `BYPASS_ACT` an unavoidable gate? |
|---|---|
| `CANONICAL_CELLULAR_STATE` | no |
| `FUNCTIONAL_CELLULAR_TARGET` | no |
| `ORGANISM_TARGET` | no |

Distances and unavoidable-branch counts for each destination are in the appendix; the finding
that matters here is semantic rather than numeric.

**`BYPASS_ACT` is not an unavoidable gate to either cell-level destination.** Checkpoint
activation is therefore a route-specific requirement and a mechanistic diagnostic, not a
universal target conjunct — several iterations were spent hunting a component a synthetic
architecture may not need. It stays in the map and in the canonical state; it no longer gates
the functional target.

What replaced it is narrower and honest: `ACT_SAFETY01`. Checkpoint deficiency predisposes to
tumours by a route the missegregation endpoint cannot see, and this disorder already carries
embryonal tumour risk. So the question is not "must the checkpoint signal" but "does this case
need checkpoint competence for reasons other than fidelity" — and that is now the one
unavoidable branch on the functional target.

## Grounded facts traversed without branching

Per the PRD: a sufficiently grounded transition is traversed directly, with its applicability
boundary recorded, rather than being split into alternative worlds because it has caveats.

- **`G_KINASE_DISPENSABLE`** — Neither kinase activity nor the 265-residue kinase domain is required for checkpoint or stable attachments (731X restores both) [PMID:20516114]
  - *consequence:* Any route premised on restoring BubR1 kinase activity is eliminated and does not appear in this map
- **`G_SEPARABLE`** — Alignment and checkpoint are separable functions (Y155C restores alignment and not checkpoint; 483X the converse) [PMID:20516114]
  - *consequence:* Composite bypass must supply each function separately; one component is not assumed to cover both
- **`G_ALIGN_REGION`** — Stable kinetochore-microtubule attachment relies on the central region 484-715 [PMID:20516114]
- **`G_ACT_REGION`** — The N-terminal TPR domain is required for checkpoint signalling via KNL1/Blinkin [PMID:20516114]
- **`G_MECHANISM`** — For the reference substrates, low abundance arises from HSP90-dependent misfolding and proteasomal clearance at normal transcript level [PMID:20516114]
  - *consequence:* Grounds P1/P2 in the destabilising direction only
- **`G_SIRT2`** — SIRT2 activity and BubR1 abundance are coupled through K668 acetylation: raising SIRT2 raises abundance in mouse tissue, inhibiting Sirt2 destabilises BubR1 in human cells [PMID:24825348, PMID:25672491]
  - *consequence:* A grounded relation, untested on a misfolding substrate; it is the best-grounded candidate mechanism for STAB01 and grounds no rescue direction
- **`G_BUBR1_REQUIRED_FOR_CONGRESSION`** — BubR1 is required for the initiation of chromosome congression independently of its role in recruiting CENP-E, and its absence cannot be compensated by inhibiting Aurora kinases [PMID:41120314]
  - *consequence:* Raises the bar for any alignment bypass: the function to be supplied is one BubR1 is directly required for, not merely one it assists
- **`G_NO_LIMITING_EXPERIMENT`** — Across all five full texts adjudicated, every experiment ran at BubR1-present or BubR1-absent (siRNA or degron depletion). None ran at BubR1-limiting [PMID:41120314, PMID:38354735, PMID:41218610, PMID:39541344, PMID:30341343]
  - *consequence:* This case is BubR1-limiting, not BubR1-null. Every dependency verdict in the literature is therefore about a different regime, and that is why each dependency branch keeps an `unestablished` outcome rather than resolving on the published work
- **`G_LOCALISATION_NOT_FUNCTION`** — A BubR1-independent route can target a component to the kinetochore without being shown to deliver the component's function [PMID:38354735, PMID:41120314]
  - *consequence:* The same distinction Y155C forces inside this case: normal localisation with a dead function. A bypass candidate must be adjudicated on its function, never on its localisation
- **`G_THREE_FAMILIES`** — Three route families are distinguishable once independence stops being a success criterion: F1 repairs or stabilises the defective protein, F2 supplies a lost function without it, and F3 exploits the residual function that is present while altering a different physical process [derived: Structural consequence of this map, not a literature claim: it follows from defining the functional target by the terminal cellular state and from DEP_FLUX carrying independence as a classification rather than a success criterion]
  - *consequence:* F3 is only visible because the functional target is defined by the terminal cellular state rather than by the canonical trajectory. An approach that required repairing the gene first would not look for it
- **`G_KEN_SELF_DEFEATING`** — The BubR1 KEN degron is also required for checkpoint function [PMID:17406666, PMID:20516114]
  - *consequence:* Degron disruption is excluded as a stabilisation route on function grounds, not evidence grounds

## Latent control variable sweep

The motif pass asked what repeats in the graph. This asks something harder: whether three or

Without that it is a new name for a pattern already in hand, and renaming is not explaining.

### `LV1_KINETOCHORE_PHOSPHATASE_CAPACITY` — BIOLOGICAL_LATENT_VARIABLE

**Candidate variable.** Kinetochore kinase-phosphatase balance — specifically PP2A-B56 phosphatase capacity delivered to kinetochore and centromeric substrates, for which BubR1 is a scaffold.

**Neighbourhoods explained:** `CV_CHROMOSOME_ALIGNMENT`, `CV_ATTACHMENT_TURNOVER`, `CV_CHECKPOINT_SILENCING`, `CV_COHESION_PROTECTION`.

*Shared:* physical substrate, molecular machinery, dependency pattern, localisation, experimentally coupled readouts.

**Why one variable could generate all of them.** Each of the four is read out as the phospho-state of a substrate at the kinetochore or centromere, and each has a phosphatase in its own actuator list that the city recorded separately: CENP-E counters Aurora B phosphorylation to stabilise attachments, Astrin-PP1 counteracts Cyclin-B-CDK1 to protect them, PP1/PP2A at KNL1 silences the checkpoint, and SGO1 recruits PP2A to protect centromeric cohesin from phosphorylation-dependent removal. The city modelled four variables with disjoint actuators because it built each street separately. One quantity — how much phosphatase reaches those substrates — would move all four.

**Existing evidence.**

- PMID:37712330 / PMID:PPR497110 — a bifunctional kinase-phosphatase module balances mitotic checkpoint strength and kinetochore-microtubule attachment, and integrates checkpoint with error-correction signalling. The literature already treats these two as one module; the city did not.
- PMID:33125045 — kinetochore phosphatases suppress autonomous Plk1 activity to control the checkpoint.
- PMID:41120314 — CENP-E counters Aurora B-mediated phosphorylation in a BubR1-dependent manner, and does so through BubR1-PP2A.
- PMID:20516114 — stable kinetochore-microtubule attachment relies on the central part of human BubR1 (484-715), which is where the PP2A-recruitment motif of this protein sits.
- EXP01 already carries kinetochore PP2A-B56 recruitment (E01_PP2A) as an OPTIONAL mechanistic readout. If this hypothesis holds, the optional readout is the primary discriminator.

**Structural facts, verified against retrieved full text.** This replaced a flagged
guess, and the answer came back more specific than the guess was.

- *kard span* — Residues 665-682. "The KARD, spanning residues 665 to 682, is a highly conserved domain" (PMID:33892776).
- *b56 binding segment* — Residues 668-675. "The KARD encompasses the B56 binding site, identified as a LxxIxE motif contained within residues 668-675 (K L SP I I E D)" (PMID:33892776).
- *k668 position* — K668 is structurally present at the B56 interface: "four sites in particular, K668, L669, I672 and E674, were identified to physically interact" (PMID:33892776). It is not one of the three critical positions — the LxxIxE core is leucine at position 1, isoleucine at 4, glutamate at 6 (PMID:40684918), which on this sequence are L669, I672 and E674. K668 precedes position 1.
- *k668 acetylation scope* — The SIRT2/K668 evidence establishes stability and degradation control, not PP2A-B56 recruitment: "K250 and lysine 668 (K668)... regulate BubR1 protein stability in opposite manners" (PMID:33892776), and PMID:24825348 measures abundance.
- *unverified remainder* — That a K668 alanine substitution has only a modest effect on B56 binding is recorded as supplied and NOT grounded: the retrieval guard refuses a residue-plus- substitution query as case-specific protein-change shorthand, failing closed as it should. It is not load-bearing — interface-but-not-critical is established by the quotes above.

**Retrodiction, from data not used to build the city's variables.** The partition this variable implies — phosphatase-scaffolding readouts coupled, checkpoint ACTIVATION separable because it runs through the TPR-KNL1 interaction rather than through phosphatase delivery — matches all four separation-of-function alleles in the case's own source, none of which was used to define the city's control variables. 731X retains 1-715 and the recruitment region: restores alignment. 483X lacks 484-1050 and therefore the region: fails alignment. Y155C is TPR and retains the region: restores alignment, loses checkpoint activation. R550Q is central and intact: restores both. Four alleles, four predictions, four matches.

**New predictions** — none of these was used to construct the hypothesis.

- Co-movement: perturbing PP2A-B56 recruitment at fixed BubR1 abundance should move alignment, attachment turnover, checkpoint silencing and cohesion together, while checkpoint ACTIVATION remains separable. The city predicts no such coupling; it treats them as four variables.
- Kinetochore PP2A-B56 should be reduced in this case's allele in proportion to the integrity of the recruitment region, independently of total protein abundance — which is a different axis from the abundance premise CHAR01 tests.
- A route that lowers missegregation by restoring phosphatase delivery should improve PCS as well, because centromeric cohesin protection is PP2A-dependent. That predicts COUPLING01's answer rather than waiting for it.

**Evidence against, and incompatibilities.**

- The dissociations could instead reflect two independent BubR1 functions rather than one variable plus one separable arm. The hypothesis is not distinguished from that by the retrodiction alone, which is why the co-movement prediction is the test.
- Astrin-PP1 and PP2A-B56 are different phosphatases. Treating them as one capacity is a simplification the co-movement experiment would expose.
- K668 being at the interface does not make the acetylation functional there. The residue is outside the three positions that carry binding, so the structural fact constrains the bridge hypothesis below rather than supporting it.

**Smallest discriminating experiment.** In a BubR1-limiting human cell line, perturb PP2A-B56 kinetochore recruitment alone — by the B56-binding motif rather than by BubR1 — and measure, in the same cells: kinetochore PP2A-B56, chromosome alignment, k-fibre turnover, time to anaphase, premature chromatid separation and the nocodazole response. The hypothesis predicts the first five move together and the sixth does not. The city predicts no particular relationship among any of them.

**Status.** `NOT_TRAVERSABLE`. Promotion requires: The co-movement result above. The recruitment-motif coordinates are now verified, so that leg is closed.

#### Bridge hypothesis `BR1_K668_ACETYLATION_TO_PHOSPHATASE_DELIVERY` — `NOT_ESTABLISHED`

Kept separate from the parent on purpose: it would connect two districts, so it must
not be able to borrow the parent's support.

**Claim.** K668 acetylation state alters kinetochore PP2A-B56 recruitment, independently of BubR1 abundance — which would connect abundance control (F1, through SIRT2) to phosphatase-delivery control (LV1) through one residue.

**Established.** K668 is at the B56 interface. K668 acetylation regulates protein stability. Both separately, from retrieved sources.

**Not established.** Any relation between the acetylation state and recruitment. No retrieved source connects them, and the structural fact argues mildly against it: K668 lies outside the three positions that carry B56 binding.

**Discriminating question.** Does K668 acetylation state alter kinetochore PP2A-B56 recruitment independently of BubR1 abundance?

**Experiment.** Compare acetylation-mimetic and non-acetylatable K668 constructs at MATCHED abundance, and measure kinetochore PP2A-B56 per kinetochore. Matched abundance is the whole design: without it the known stability effect confounds the recruitment readout.

**Falsification is asymmetric.** A negative result kills this bridge ONLY. LV1 rests on the four neighbourhoods sharing a phosphatase substrate and on the four-allele retrodiction, neither of which involves K668. A positive result creates a candidate cross-district mechanism connecting abundance control to phosphatase delivery — which is why it is worth asking even though the structural fact leans against it.

*F1 and LV1 stay separate. This bridge is not in `edges`, not in `control_variables`, and contributes nothing to reachability.*

### `LV2_PROTEOSTASIS_CAPACITY` — BIOLOGICAL_LATENT_VARIABLE

**Candidate variable.** Cellular proteostasis capacity — chaperone availability relative to client load — as a quantity that scales with cell volume and differs between euploid and aneuploid populations.

**Neighbourhoods explained:** `CV_BUBR1_ABUNDANCE`, `CV_CELL_SIZE`, `CV_CLONAL_DYNAMICS`.

*Shared:* molecular machinery, failure pattern, compensatory behaviour.

**Why one variable could generate all of them.** The case's own mechanism is chaperone-dependent misfolding: mutant BubR1 collapses under HSP90 inhibition while wild-type barely moves. Chaperone capacity is not a constant — it scales with volume and with client load, so an enlarged cell and an aneuploid cell are both cells whose proteostasis budget is under strain. One variable would then set the mutant protein's abundance, the size-dependent error rate, and the relative fitness of euploid against aneuploid populations, which the city models as three unrelated things in three different families.

**Existing evidence.**

- PMID:20516114 — the mutant protein's abundance is HSP90-dependent and proteasome-cleared; chaperone capacity is already the grounded mechanism for CV_BUBR1_ABUNDANCE.
- PMID:41265458 — HSP90 buffers deleterious genetic variation in another protein, so chaperone capacity is a general modifier of missense variant behaviour rather than a BubR1 quirk.
- PMID:42596742 — a Down syndrome critical region gene is a mammalian cell size regulator, which is an independent link between an aneuploid state and cell size.
- PMID:PPR1045515 — cell enlargement causes mitotic errors and aneuploidy.

**New predictions** — none of these was used to construct the hypothesis.

- Perturbing chaperone capacity should move the size-dependent error rate, not only BubR1 abundance. The city has no edge between those two districts.
- Aneuploid and euploid populations in the same dish should differ in sensitivity to chaperone perturbation — which would make one perturbation act on F1 and F4 simultaneously, families the city places at opposite ends.
- The stabilisation result should depend on cell size: the same perturbation should raise the mutant protein more in small cells than in large ones.

**Evidence against, and incompatibilities.**

- The decisive link is missing. A bounded search for selective chaperone vulnerability of aneuploid cells returned nothing usable, so the F1-to-F4 bridge rests on mechanism rather than on a measurement. This hypothesis is materially weaker than LV1 and is recorded as such.
- Cell size and proteostasis could both be downstream of cell-cycle length rather than of each other, which would make LV3 the real variable and this one a correlate.

**Smallest discriminating experiment.** One experiment, three readouts: perturb chaperone capacity across a cell-size gradient in a BubR1-limiting line and measure mutant protein abundance, missegregation rate, and the euploid versus aneuploid fraction over several divisions. The hypothesis predicts all three move; the city predicts only the first.

**Status.** `NOT_TRAVERSABLE`. Promotion requires: A measured difference in chaperone sensitivity between euploid and aneuploid populations, which no retrieved document currently provides.

### `LV3_MITOTIC_DURATION` — BIOLOGICAL_LATENT_VARIABLE

**Candidate variable.** Time spent in mitosis, as a quantity that both the checkpoint sets and the cell's fate depends on.

**Neighbourhoods explained:** `CV_CHECKPOINT_SILENCING`, `CV_CHROMOSOME_ALIGNMENT`, `CV_CELL_SIZE`, `CV_CLONAL_DYNAMICS`.

*Shared:* temporal behaviour, experimentally coupled readouts, failure pattern.

**Why one variable could generate all of them.** Duration is downstream of alignment and of silencing, and upstream of death, slippage and the next cell cycle's length. The case's own source shows the coupling without naming it: 483X restores the checkpoint, fails alignment, and the consequence recorded is a significantly extended mitosis. Duration is therefore a shared readout of two of the city's variables and a driver of two others.

**Existing evidence.**

- PMID:20516114 — failed alignment with an intact checkpoint produces extended mitosis.
- PMID:40884189 — mitotic duration has a defined role in cell fate determination.
- PMID:30341343 — TRIP13 and APC15 set the time to exit, and losing both produces chronic arrest.

**New predictions** — none of these was used to construct the hypothesis.

- Two routes that lower missegregation by the same amount should be distinguishable by whether they changed mitotic duration, and the one that lengthened it should carry the worse viability and division endpoints. The city treats those endpoints as independent safety readouts.
- The safety endpoints across every F2 and F3 route should correlate with duration rather than with which function was supplied.
- If duration is the variable, an actuator that shortens mitosis should worsen fidelity even while improving the population endpoints — a tradeoff the city cannot currently express.

**Evidence against, and incompatibilities.**

- Duration may be a consequence rather than a cause across most of these neighbourhoods, in which case it is a useful shared readout and not a control variable. The third prediction is what separates those: a cause can be pushed in the unhelpful direction.
- Nothing connects duration to cell size in the retrieved evidence; that link is the weakest leg of the four.

**Smallest discriminating experiment.** Record time from mitotic entry to anaphase in every arm of every route already specified, which costs nothing extra because the live imaging is already there, and test whether the viability, death and division endpoints track duration better than they track the identity of the function supplied.

**Status.** `NOT_TRAVERSABLE`. Promotion requires: The correlation above, plus one actuator that moves duration independently of the functions.

### What the map says about priority

No single branch gates every route, because the two families are genuinely alternative. The
decision-relevant fact is which branch gates a whole family:

| family | unavoidable branches |
|---|---|
| F1 abundance | `CHAR01`, `EXP01`, `SAFE02` |
| F2 bypass | `DEP_KIF18A`, `SAFE01` |

The two families are blocked by different kinds of thing. **F1** is a strict chain: all
3 of its branches are unavoidable and 3 are runnable measurements, so it
is long but every step is work someone can do. **F2** is gated by
runnable measurements only.

So the bypass family is not blocked by effort but by the absence of a thing. A route cannot be
assembled from two supplied functions and a missing one.

The shortest route holds **2 runnable measurements of 2**, and no discovery.

Two readings, and where they disagree is the useful part. **By branch count** the bypass family
is shorter. **By kind**, what matters is how many of those branches are measurements someone can
run rather than components nobody has described — which is why the external search mattered more
than another pass over the graph.

`CHAR01` remains the leading runnable experiment on the abundance family: the corrected graph
still makes it unavoidable for F1, it is the cheapest branch on that family, and it needs no
patient material — one construct, a cycloheximide chase with HSP90 inhibition and MG132, a
strict subset of what STAB01 already specifies.

It is not EXP01, and the reason is about the premise rather than the question. `EXP01` asks whether
the altered protein works at matched abundance. `CHAR01` asks whether the premise underneath that
question holds for this allele at all — and the premise is class-level inference: `MC_0006` is
`UNRESOLVED` on zero establishing records, `MC_0005` rests on 0 establishing and 11 indirect, and
Q921H is a kinase-domain substitution normal in both level and function. If this allele is not
destabilised, EXP01's matched-abundance framing is miscast before it is run.

### What the external search changed

The three component-discovery diamonds were the map's biggest holes. Function-first discovery
against external literature, followed by dependency adjudication, replaced two of the three with
named candidates:

- **alignment** — `CENP-E` is **closed by evidence**, which is the most useful single result: it
  has a BubR1-independent route to the outer corona, while the mechanism by which it initiates
  congression is explicitly BubR1-dependent. Localisation is not function, the same distinction
  Y155C forces. `KIF18A` and microtubule `poleward flux` survive as named candidates with their
  dependency unestablished.
- **silencing** — `TRIP13` with `APC15` survives as a named candidate. It carries a specific extra
  risk the map records as its own outcome: the same protein maintains open-state Mad2 for
  checkpoint activation, so augmenting it for silencing may trade one broken function for another.
- **activation** — nothing survived function-first discovery. This stays a bounded external
  frontier, not an impossibility: `NOT_FOUND_IN_SEARCHED_EXTERNAL_UNIVERSE`, with the searched
  universe recorded in `data/literature/mva-bypass-v1`.

Absence of a known BubR1 link was never recorded as independence. Every surviving candidate's
dependency branch has an `unestablished` outcome, and that is where they all sit today.
