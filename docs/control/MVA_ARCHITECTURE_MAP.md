This report contains no treatment recommendation and no clinical advice. It states which biological transformations would, under the stated models, move the system into the target region, and which of them nothing is known to implement. Deciding whether any of it is worth testing is a judgement for a scientific lead and a treating clinician.

Every architecture above is a statement of the form: *if these transformations were achievable and this model is right, the system would enter the target region.* The first condition is unmet for every component listed, and the second is a target definition no accountable scientist has yet approved.
